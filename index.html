Flickerkeep

Flickerkeep is a private, self-hosted personal assistant that its developer built for their own use. It is not a commercial product or a public service, and there is no sign-up. This page exists because Google requires a homepage for apps that use Google sign-in.

With the owner's permission, Flickerkeep can:

  • read the owner's Google Calendar, and add entries only to a separate calendar that Flickerkeep creates;
  • read the owner's Gmail (it does not send, change or delete mail);
  • keep the owner's encrypted backups in Google Drive, using only files it created itself.
